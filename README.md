Core Concepts and Skills - Web Development Internship

This repository contains hands-on practice exercises, mini-projects, and code samples developed during the **Core Concepts and Skills** phase of the Web Development internship.

## 📂 Project Structure
* `index.html` - Semantic HTML structure showcasing layout fundamentals.
* `style.css` - CSS styles demonstrating responsive design, Flexbox, and Grid principles.
* `script.js` - JavaScript code covering DOM manipulation, event handling, and logic implementation.
